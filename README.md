# SFQ 2026-27 — дашборд студенческих анкет

Дашборд на Streamlit по трём анкетам учебного года:

| Анкета | Содержание | С чем сравнивается |
|---|---|---|
| **Осень** — начало учебного года | Ожидания, нагрузка, удержание, внеучебная жизнь | С осенними анкетами других лет |
| **Зима** — итоги 1-го семестра | SFQ, как в 2025-26: удовлетворённость, NPS, CSI, преподаватели | С весенней анкетой |
| **Весна** — итоги 2-го семестра | SFQ | С зимней анкетой |

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для Streamlit Community Cloud укажите файл `app.py` и Python 3.11. Дашборд использует только папки `data/processed/`, `docs/` и файл `data/reference/contingent.csv`.

## Структура

```
app.py                      точка входа: выбор анкеты на боковой панели
dashboard/common.py         фильтры, отклик и погрешность, статистика, оформление
dashboard/autumn.py         осенняя анкета (10 вкладок, включая «Внеучебную жизнь» и «Сравнение по годам»)
dashboard/sfq.py            зимняя и весенняя анкеты (вкладки SFQ 2025-26: NPS, CSI, преподаватели и др.)
process_autumn.py           выгрузка осени → data/processed/autumn_<год>.csv
process_sfq.py              выгрузки зимы и весны → data/processed/sfq_<волна>.csv
process_contingent.py       Контингент.xlsx → data/reference/contingent.csv
survey_utils.py             общие функции обработки (нормализация текста, реестр программ)
data/reference/programs_registry.csv   программа → школа, уровень
docs/codebook_autumn.md     кодификатор осенней анкеты (создаётся скриптом process_autumn.py)
docs/codebook_sfq.md        кодификатор SFQ (составлен по анкете 2025-26)
notebooks/clean_data.ipynb  исходный ноутбук предварительной очистки (заменён скриптом process_autumn.py)
```

## Обновление данных

**Осень.** Положите выгрузку из Тестографа в `data/raw/autumn/autumn.csv` и запустите:

```bash
python process_autumn.py
```

Скрипт сопоставляет столбцы по тексту вопроса, а не по номеру, поэтому не зависит от перенумерации вопросов и новых блоков для курсов. Вопросы, которые не удалось сопоставить, выводятся с пометкой `WARNING` — добавьте их в `QUESTION_MAP`.

**Зима и весна.** Положите выгрузки по программам (по одному файлу xlsx или csv на программу; имя файла — название программы, приписки вида «(2 сем)» и «(зима)» отбрасываются) в `data/raw/winter/` или `data/raw/spring/` и запустите:

```bash
python process_sfq.py winter
```

```bash
python process_sfq.py spring
```

Если формулировка вопроса изменилась, он попадёт в список несопоставленных столбцов — добавьте новую формулировку в `COL_MAP`.

**Контингент** (для расчёта отклика и погрешности). Положите `data/reference/Контингент.xlsx` в формате 2025-26 и запустите `python process_contingent.py`.

**Сравнение по годам.** Каждый файл `data/processed/autumn_<ГГГГ-ГГ>.csv` (вместе с `_meta.json`) считается отдельным учебным годом. В следующем году скопируйте сюда (или в репозиторий 2027-28) файлы осени 2026-27 — вкладка «Сравнение по годам» заработает автоматически. Данные другого года можно подготовить так: `python process_autumn.py --raw <выгрузка.csv> --year 2027-28`.

## Персональные данные

- В git **не попадают** папки `data/raw/` (исходные выгрузки с контактами) и `data/private/`, а также файл `Контингент.xlsx`.
- В вопросе о специальных условиях обещан ограниченный доступ к ответам, поэтому в публичных данных есть только обобщённая категория `special_needs` («Нет», «Да», «Другое», «Предпочли не отвечать»). Типы потребностей, описания и контакты для учебного отдела сохраняются в `data/private/autumn_<год>_special_conditions.csv`.
- В разбивках дашборда не показываются группы, в которых меньше 5 ответов (порог настраивается).

## Реестр программ

В файле `data/reference/programs_registry.csv` указаны школа и уровень каждой программы. Для новых программ 2026-27 эти данные заполнены предположительно и отмечены в столбце «Проверить» — сверьте их.
