# Кодбук — осенняя анкета 2026-27 (`autumn_2026-27.csv`)

Стартовая анкета начала учебного года (Тестограф). Одна строка — один респондент.
Исходных ответов: **318**, исключено тестовых: **1**, в датасете: **317**.

Анкета ветвится по курсу: 1 курс получает блок про поступление (решение, олимпиады, английский),
2+ курс — вопросы про прошлый год (часы в прошлом году, мысли о переводе/отчислении, чего не хватает).

## Правила
- Множественный выбор: варианты через `; `, пустая строка — ничего не выбрано.
- Свой вариант ответа (`Впишите свой ответ`) вынесен в колонку `<var>_other`; в самой переменной он учтён как «Другое (свой вариант)».
- Для вопросов про игры ответы «не играю / ни во что» приведены к варианту «Не играю в игры этой категории», а названия игр из своего варианта — в `<var>_other`.
- Контакты и описание специальных условий **не входят** в публичный датасет (доступ к ним ограничен, см. `data/private/`).

## Служебные и производные поля

| Колонка | Описание |
|---|---|
| `resp_id` | Номер ответа в выгрузке |
| `date` | Дата и время ответа |
| `duration_sec` | Время заполнения, сек |
| `school`, `level` | Школа и уровень программы (из `data/reference/programs_registry.csv`) |
| `flag_long_time` | Анкета заполнялась дольше часа (вкладку, вероятно, оставили открытой) |
| `hours_planned_num`, `hours_last_year_num` | Середина интервала часов самоподготовки (0, 3, 8, 13, 18, 23, 28) |
| `hours_change` | Планирует тратить больше / столько же / меньше часов, чем в прошлом году (2+ курс) |
| `travel_min_num` | Середина интервала времени в дороге, мин (15, 45, 75, 105) |
| `plans_to_work` | Работает или планирует / не планирует / пока не знает |
| `special_needs` | Нуждается ли в специальных условиях: Нет / Да / Другое (свободный ответ) / Предпочитаю не отвечать |
| `retention_status` | Итог по вопросу о переводе/отчислении (2+ курс) |
| `retention_risk` | 1 — думал(а) или думает об уходе/переводе, 0 — нет; пусто — не ответил(а) / 1 курс |
